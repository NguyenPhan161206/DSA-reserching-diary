## 🎯 Platform roles

| Platform | Role | Best for |
|----------|------|----------|
| **LeetCode** | Daily driver — interview-shaped drilling | Topic-by-topic practice, company-tagged sets |
| **Codeforces** | Rating & speed under time pressure | Honest fluency test, contest tactics |
| **PTIT** | Course-aligned exercises | SE course assignments & exams |
| **VNOI / CSES / Kattis** | Structured classic suites | Curated algorithm coverage, no account needed |
| **Project Euler** | Math-heavy exploration | Only when the math interest appears |

*One platform used daily beats five used occasionally.*
